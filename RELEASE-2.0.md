# Standalone Revision R Final 2.0

Revision 2.0 is the standalone WebView2 shell release with the current
Glitch Canvas effects engine.

## Playtest files

- [Complete standalone ZIP](standalone-revision-R-final-2.0/dist/standalone-revision-R-final-2.0-standalone.zip)
- [Standalone WebView2 shell](standalone-revision-R-final-2.0/app/StandaloneRevisionRFinal.exe)
- [Windows launcher](standalone-revision-R-final-2.0/Launch-Standalone-Revision-R-Final-2.0.cmd)
- [Startup sizing script](standalone-revision-R-final-2.0/Start-Standalone-Revision-R-Final-2.0.ps1)
- [Current Glitch Canvas UI](standalone-revision-R-final-2.0/webui/glitch-canvas.html)
- [Current effects stylesheet](standalone-revision-R-final-2.0/webui/glitch-canvas.css)

The launcher starts the real standalone shell window at 1280x720. Use
Alt+Enter to switch between windowed and fullscreen modes. Ghost Protocol and
V-Sync Scan are included in the current effects UI.

The ZIP is the recommended download because the shell executable requires its
neighboring runtime files and `webui` directory.
