# Glitch Player R4.0 -> R4.1 "Definition & Confluence" (December 2026) - dream plan

Grounded in standalone-revision-R-final-4.0 (43 voices, 80 MACHINE + 250 LAB presets, landing card, link tree,
GHOST // OF ME, HUD, effects canvas, landing-backdrop, frame governor). Photosensitivity caps (Flash 20%, Strobe 35%) and
the security posture (no bypasses, no new network, no new native deps) are fixed constraints.

## Theme
One authoritative, machine-checked definition of every preset, effect and surface, so docs, code and tests cannot drift.

## 1. Definition layer (single source of truth)
- `webui/data/effects.manifest.json`: per voice id, name, origin (Canvas / R3 / AI WARP), twin id, range, default 0,
  cap, glyph-bank use, cost tier (governor), photosensitivity class, canvas layer + draw order.
- `webui/data/presets.schema.json` (JSON Schema): name 1-80, <=128 effects, locks, caps; shared by import/export,
  MACHINE, LAB 250, USER and GHOST.
- `webui/data/surfaces.manifest.json`: landing card, link tree, MISSING LINK card, HUD regions, floating controls,
  canvas stack. Each lists states (idle/hover/focus/playing/paused/reduced-motion), animations, timers (10 s gleam,
  24 s hue, ~30 s card turn, 26 s tree wave) and keyboard map.
- Tests: extend effects-manifest.test.mjs to fail if code, manifest and docs disagree; add preset-schema and
  surfaces tests.

## 2. Confluence docs (generated, not hand-written)
`tools/build-docs.mjs` renders `docs/` from the manifests (CI fails when stale; also exports a Confluence-ready
storage-format/markdown bundle):
- Effects reference: all 43 voices + AI WARP masters (DROP THE MILK?, B&W Strength, Hue Offset), with ranges, twins,
  glyph-bank assignment order and governor cost tier.
- Preset reference: MACHINE 80 and LAB 250 index (name, effects used, caps applied), USER/import/export format,
  lock semantics, preset glide, AUTO cycler.
- Ghost: GHOST // OF ME flow diagram (Ctrl+Alt+G, confirmation, MISSING LINK reveal, crimson backdrop, capped levels).
- Init landing: logo card, gold/silver sheen, prism band, link tree, backdrop (glyph rain), reduced-motion behaviour.
- Main HUD and canvas: layout under the 36 px bar, panels, canvas layers, frame governor steps, Freeze Frame.
- Keyboard, security and photosensitivity pages cross-linked.

## 3. Product improvements (small, safe)
- Preset browser: search, tags (derived from manifest), diff-vs-current, "why is this slider 0?" lock/cap indicator.
- Effect inspector: hover card per voice (origin, twin, cost tier) from the manifest.
- Accessibility pass: focus order across landing -> tree -> HUD, ARIA labels, contrast check, reduced-motion parity.
- Governor telemetry overlay (opt-in, local only) and per-voice cost warnings.
- Optional: sign-ready build pipeline docs (no signing performed without your certificate).

- glitch-player.js is ~600 KB: extract by test-guarded steps, never rewrite wholesale.
- Docs claims must match code (counts: 43 voices, 125 glyph tables, 330 built-in presets) - enforced by tests.
- Any new motion must respect reduced-motion and the flash/strobe caps.
