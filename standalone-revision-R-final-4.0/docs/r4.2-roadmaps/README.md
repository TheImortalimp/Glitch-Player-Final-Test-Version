# Roadmaps beyond 4.1 - index

Written against Standalone Revision R Final 4.1.0 "Definition & Confluence" (43 voices, 80 MACHINE + 250 LAB presets,
125 glyph tables / 127,648 code points, machine-checked manifests, frame governor, SOFT-EYE engine).

Fixed constraints in every roadmap: Flash 20% / Strobe 35% caps and the sub-3 Hz rate, confirmation-gated automation,
reduced-motion parity, no telemetry, no new network surface, no new native dependencies, CC0 licence.

| Roadmap | Theme |
| --- | --- |
| [TOTAL-CONFLUENCE.md](TOTAL-CONFLUENCE.md) | One engine, one definition layer, generated docs - the end state of "Definition & Confluence" |
| [AESTHETICS.md](AESTHETICS.md) | The look: landing, HUD, cards, glyph voices and colour language |
| [TRANSITION-TIMING.md](TRANSITION-TIMING.md) | Glide/cut characters, timing jitter, musical and clocked transitions |
| [PRESET-RANDOMIZATION-AND-LEARNING.md](PRESET-RANDOMIZATION-AND-LEARNING.md) | MACHINE re-rolls, seeded decks, and local-only taste learning |
| [REBUILDING.md](REBUILDING.md) | Reproducible rebuilds of tables, manifests, presets - and the modular rebuild of glitch-player.js |

Each roadmap is standalone: phases, exit criteria and risks. None of them is scheduled; they are build-ready plans.
