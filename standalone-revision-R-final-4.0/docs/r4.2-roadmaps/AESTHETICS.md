# Roadmap - Aesthetics

The 4.x look: gold [R] card with silver sheen, turning gold-and-silver rim, sparkle glints, prism band, GHOST PROTOCOL
glyph rain, link-tree gleam waves, REVISION 4 // HARD LIGHT // MOONLIGHT. 4.1 loosened the SOFT-EYE engine's
non-light aesthetic limits (ASCII, Matrix, bombs) and polished the landing card and link tree. This roadmap takes the
look further without ever touching the light caps.

## Principles
- Lights are safety; everything else is taste. Flash/Strobe caps, sub-3 Hz and confirmation gates never move.
- Reduced motion is a first-class theme, not a fallback: every new animation ships with its still form.
- The palette is the engine's own: DIA, SPECTRUM, CRT, PLASMA and LED hue families, already cycled by the backdrop.

## Phases
| Phase | Outcome | Exit criteria |
| --- | --- | --- |
| 1. Colour language | A named palette table in `surfaces.manifest.json` (hue families, accents, armed crimson), used by landing, HUD, cards and backdrop | No hard-coded hues left in CSS/JS for themed surfaces; contrast checked per pairing |
| 2. Material pass | The gold/silver/prism treatment becomes a reusable "card material" (sheen, rim, glints, refraction band, turn-the-wheel moment) applied to the logo card, link tree, MISSING LINK and future preset-browser cards | One implementation, per-surface timers from the manifest (10 s gleam, 24 s hue, ~30 s turn, 26 s wave) |
| 3. Glyph aesthetics | Per-table "flavour" hints (weight, density, astral share) derived from the guarded tables, so voices can bias composition without new data sources | Hints generated by `build-glyph-tables.mjs`; `--check` covers them |
| 4. HUD polish | Typography and spacing pass under the 36 px bar; slider states (locked, capped, automated) get distinct, colour-blind-safe looks | Focus order, ARIA and contrast verified; reduced-motion parity kept |
| 5. Scene moods | Optional curated "mood" overlays (e.g. MOONLIGHT, TERMINAL 1987) that combine palette + material + glyph flavour, defined as data | Moods are manifest entries, not code paths; all moods respect caps and reduced motion |

## Risks
- Beauty creep into the light channels: any effect that modulates luminance at frame rate is classed photosensitive
  and lives behind the existing gates, no exceptions.
- Rare-script tables render as boxes on fontless systems; flavour hints must not make them more prominent.
